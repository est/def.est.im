# DESIGN_NOTES — def.est.im 原型设计记录

> 本文件供后续设计迭代参考。

## 方向（2026-08-09，v2）

**产品**：AI-native 语言学习词典。核心单位 = lexical unit。交互原则：Search first, explain second。

**视觉语言**：没有设计就是最好的设计。黑白灰为主，系统字体，无装饰，信息密度优先。像一本排版干净的参考书，不是 app。

令牌（见 public/style.css）：
- `--fg: #111` · `--muted: #666` · `--rule: #ddd` · `--bg: #fff`
- 无强调色。链接默认色。极少量蓝色用于可交互元素。

## 页面

- `index.html` — 空状态：输入框 + 使用说明
- `entry.html` — 词条页：词头 + 核心概念 + 释义(10义) + 词形 + 搭配 + 短语 + 词源
- `style.css` — 共享样式（3KB）

## 取舍

- **v1→v2 改动**：删除 SVG 语义图、语域刻度尺、卡片堆叠、学习模式、探索页、关系图、印章红。全部换成纯文字列表。
- **保留的**：信息结构（核心概念/释义/词形/搭配/短语/词源）、中文释义+英文释义双行、紧凑排版。
- 词条页用 `?w=` 参数，方便后续接真实后端。

## 验证

- 2 页 HTML 标签配平
- 对比度：最暗 #111/#fff = 18.9:1，最弱 #666/#eee = 4.9:1，全通过
- 总体积 < 10KB（3 文件）
- 375px 无横向溢出（CSS 网格 + body padding 兜底）
